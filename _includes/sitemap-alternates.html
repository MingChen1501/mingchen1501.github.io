{%- comment -%} Sitemap hreflang alternates (#98). Given a shared `ref` (include parameter), the English and Vietnamese URLs are resolved by the shared `ref-urls.html` partial (the same sources as `lang-alternates.html`) and this include emits absolute `xhtml:link` alternates (`en` / `vi` plus `x-default` pointing at English, the default language). Docs without a `ref` get no alternates. Plain `for` loops only (no `sort`/`where` filters): `site.vi_posts` is nil when the collection is undefined (the upstream `_config_theme-dev.yml` CI build in `script/cibuild`), and `for` over nil degrades to nothing while a filter would crash. {%- endcomment -%} {%- assign sitemap_ref = include.ref | default: '' -%} {%- if sitemap_ref != '' -%} {%- include ref-urls.html ref=sitemap_ref -%} {%- assign sitemap_en = ref_en -%} {%- assign sitemap_vi = ref_vi -%} {%- assign site_url_stripped = site.url | strip -%} {%- if sitemap_en != '' -%} {%- endif -%} {%- if sitemap_vi != '' -%} {%- endif -%} {%- if sitemap_en != '' -%} {%- endif -%} {%- endif -%}

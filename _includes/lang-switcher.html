{%- comment -%} Language switcher (#93, redesigned #122). Rendered in the header row on every page/post that carries a `ref`: links to the counterpart in the other language when one exists, otherwise falls back to the other language's home (both always exist, so the switcher never 404s). Pages without a `ref` (404, feeds, standalone demos) render no switcher. Compact pill control (#122): inline globe icon (`aria-hidden`) + short target code (`EN` / `VI`); the full target language name stays available as the accessible name (`aria-label`) and `title`, with a `lang` attribute on the code and `hreflang` on the link. It lives in the header row — never inside the collapsible nav panel (`#nav-menu`) and never in the sidebar — so it cannot break the sidebar's 5-row budget (#65). {%- endcomment -%} {%- assign switch_ref = page.ref | default: '' -%} {%- if switch_ref != '' -%} {%- assign switch_cur = page.lang | default: site.lang | default: 'en' -%} {%- if switch_cur == 'vi' -%} {%- assign switch_other = 'en' -%} {%- assign switch_code = 'EN' -%} {%- assign switch_name = 'View this page in English' -%} {%- assign switch_home = '/' -%} {%- else -%} {%- assign switch_other = 'vi' -%} {%- assign switch_code = 'VI' -%} {%- assign switch_name = 'Xem trang này bằng tiếng Việt' -%} {%- assign switch_home = '/vi/' -%} {%- endif -%} {%- assign switch_url = switch_home -%} {%- comment -%} Counterpart lookup (#104) is shared with the hreflang alternates via `ref-urls.html`: first match wins, so the jekyll-paginate page-2..N duplicates of the index (carrying the same `ref: home`) never overwrite the canonical homes, and hand-paginated `vi/pageN/` URLs are skipped outright — no switcher ever targets `/pageN/`. {%- endcomment -%} {%- include ref-urls.html ref=switch_ref -%} {%- if switch_other == 'vi' -%} {%- if ref_vi != '' -%} {%- assign switch_url = ref_vi -%} {%- endif -%} {%- else -%} {%- if ref_en != '' -%} {%- assign switch_url = ref_en -%} {%- endif -%} {%- endif -%} {{ switch_code }} {%- endif -%}

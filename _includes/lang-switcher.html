{%- comment -%} Language switcher (#93, redesigned #122). Rendered in the header row on every page/post that carries a `ref`: links to the counterpart in the other language when one exists, otherwise falls back to the other language's home (both always exist, so the switcher never 404s). Pages without a `ref` (404, feeds, standalone demos) render no switcher. Compact pill control (#122): inline globe icon (`aria-hidden`) + short target code (`EN` / `VI`); the full target language name stays available as the accessible name (`aria-label`) and `title`, with a `lang` attribute on the code and `hreflang` on the link. It lives in the header row — never inside the collapsible nav panel (`#nav-menu`) and never in the sidebar — so it cannot break the sidebar's 5-row budget (#65). {%- endcomment -%} {%- assign switch_ref = page.ref | default: '' -%} {%- if switch_ref != '' -%} {%- assign switch_cur = page.lang | default: site.lang | default: 'en' -%} {%- if switch_cur == 'vi' -%} {%- assign switch_other = 'en' -%} {%- assign switch_code = 'EN' -%} {%- assign switch_name = 'View this page in English' -%} {%- assign switch_home = '/' -%} {%- else -%} {%- assign switch_other = 'vi' -%} {%- assign switch_code = 'VI' -%} {%- assign switch_name = 'Xem trang này bằng tiếng Việt' -%} {%- assign switch_home = '/vi/' -%} {%- endif -%} {%- assign switch_url = switch_home -%} {%- comment -%} First match wins (#104): jekyll-paginate appends its page-2..N duplicates of the paginated index (carrying the same `ref: home`) AFTER the source pages, so taking the last match would point the switcher of `/vi/` at `/page2/` instead of `/`.

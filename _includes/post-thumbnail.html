{%- comment -%} Fixed-size list thumbnail (#226): every item on the list pages (`_layouts/home.html`, `_layouts/tag.html`, both languages) renders through this include, so every item gets an identical 120x90 (4:3) box. Source chain per post: front matter `thumbnail`, else front matter `image`, else the first image of the post body, else the fixed built-in placeholder (`assets/img/placeholder.svg`) for posts with no image. `post.content` here is the rendered HTML, so the body fallback splits on ` `/assets/img/thumbs/`, `-240.webp`, 240x180) and carries the same `?v=` build token as the other fixed-URL assets (see the cache rules in the `jekyll-assets` skill). External issue-attachment URLs cannot be resized — those keep this CSS fixed box and the bandwidth note lives in the README image conventions and the #226 PR body. `width`/`height` match the CSS box so the browser reserves the space before the first byte arrives (no CLS); `object-fit: cover` in `_sass/minima/custom/_list-thumbs.scss` crops inside that box without stretching it. The link repeats the title link next to it, so — like the sidebar thumbnails — it is hidden from screen readers and skipped by the tab order (`tabindex="-1"`, `aria-hidden`, empty `alt`).

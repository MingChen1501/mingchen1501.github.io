Labels and URL slugs come from `_data/tag_labels.yml` (#129), resolved by the shared `_includes/tag-label.html` partial (#175): the label follows the page language (the lifestyle pillar reads "Life" on English pages, "Đời sống" on Vietnamese ones; technical tags keep their English label in both), and the link targets the tag page of the current language (`/tags/life/` on EN, `/vi/tags/doi-song/` on VI). Post front matter keeps the canonical tag key, so unknown keys degrade to the key itself.

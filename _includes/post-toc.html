{%- comment -%} Post table of contents (#125, automatic since #134). Rendered when the post has at least `toc_min_h2` h2 headings (single constant in `_layouts/post.html`; `toc: false` suppresses it). Pages-safe by design: GitHub Pages builds with `--safe`, so the `jekyll-toc` plugin is unavailable. kramdown's own `{:toc}` marker was rejected for this job: it only expands inside the post's Markdown source, so it cannot be injected from this layout-gated include, and it would force every long post to carry the marker by hand. Instead this include builds the TOC in pure Liquid from the already-rendered `html` (kramdown emits `id` anchors on every heading via `auto_ids`, which `--safe` keeps), so no plugin and no JavaScript are needed for the list itself. Usage from `_layouts/post.html` (two mounts of this same include): {%- include post-toc.html html=content lang=post_lang mount="inline" -%} once inline at the top of `.post-content` (phones) and once as the first `.post-sidebar` section (desktop); CSS shows exactly one copy per viewport. `mount` ("inline"/"sidebar") scopes the per-branch `aria-controls` ids, so the two copies never share an element id.
